# miras.commons results: short follow-ups (October 2026)

Roadmap steps 2a to 2c of the October roadmap (miras 0.2.2, 25 runs per cell
for the E1 runs, 50 for the scenario). The curated findings are in
`commons-findings.md` (findings 23 to 26). Each part is generated by
`miras commons analyze` or copied from the scenario report; the commands are
given in each part.
